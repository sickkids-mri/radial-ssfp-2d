# Contributing

## Ways to Contribute

*   **Report Bugs**: use the [issue tracker / bug report tool] (https://github.com/sickkids-mri/radial-ssfp-2d/issues) in this Github repo to report any problems you find
*   **Propose Features**: suggest enhancements via an issue in the [issue tracker](https://github.com/sickkids-mri/radial-ssfp-2d/issues)
*   **Submit Changes**: as a [pull request from a new branch](https://docs.github.com/en/get-started/exploring-projects-on-github/contributing-to-a-project)  
    *   create a new branch for your changes (`git checkout -b your-branch-name`).
    *   commit your changes to this branch (smaller, targeted changes are easier to review).
    *   open a [pull request](https://github.com/sickkids-mri/radial-ssfp-2d/pulls) to the main repository's `main` branch, with a clear description of your changes and why they are useful.

## Assistance

If you have any questions or need further guidance, please reach out to the project team.
